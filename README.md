# Bachelor_Thesis_Energy_Spillover

Replication code for my bachelor thesis on volatility spillovers between European energy markets and sectoral equity markets.

This repository contains the code used for the empirical analysis. The original input data were obtained from Bloomberg under an institutional licence and are **not redistributed** here. To reproduce the analysis, users must obtain equivalent data through their own authorised data access and place the required files in a local `data/` directory.

## Execution Order

Run the scripts in the following order:

| Step | Thesis Section | Script | Purpose |
|---|---|---|---|
| 1 | Chapter 5 | `Pre-modeling diagnostics and innovation extraction.R` | Pre-model diagnostics and innovation extraction |
| 2 | Chapter 7 | `selection_MGARCH_model.R` | MGARCH model selection |
| 3 | Chapter 8 | `systemwide_connectedness.R` | System-wide connectedness analysis |
| 4 | Chapter 9 | `CECI.R` | Commodity–Equity Connectedness Index |
| 5 | Chapter 10 | `BK.R` | Baruník–Křehlík frequency decomposition |
| 6 | Chapter 11 | `sector_levels.R` | Sector-level connectedness and net spillovers |

Later scripts rely on outputs generated by earlier steps.
